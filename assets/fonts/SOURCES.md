# Fonts

Latin subsets, self-hosted so the site loads no external resources.

- `inter-latin.woff2`: Inter (variable, 400–700), by Rasmus Andersson. SIL Open Font License 1.1. Downloaded from Google Fonts.
- `source-serif-4-latin.woff2`: Source Serif 4 (variable, 600–700), by Adobe. SIL Open Font License 1.1. Downloaded from Google Fonts.

Chinese text falls back to the system fonts (PingFang SC, Songti SC, Microsoft YaHei).
